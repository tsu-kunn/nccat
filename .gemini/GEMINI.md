# nccat 開発ガイド

## プロジェクトの概要
`nccat`は、C言語のソースコードをコンソール上でシンタックスハイライト表示するためのツールです。`cat`コマンドのようにファイル内容を出力しますが、キーワード、コメント、文字列などを色付けし、行番号を付加して可読性を高めます。ファイルからの入力だけでなく、パイプからの標準入力にも対応しています。

## 技術スタックと構成

- フレームワーク: .NET 8.0
- 開発言語: C#
- プラットフォーム: Console
- ツールセット: dotnet CLI
- プロジェクト構成:
  * `Program.cs`: アプリケーションのエントリーポイントとメインロジック。
  * `keyword/`: シンタックスハイライトのルールを定義するディレクトリ。
    * `BaseKeyword.cs`: キーワード定義の基本クラスとJSONシリアライズ/デシリアライズ処理。
    * `C.cs`: C言語のキーワード定義。
  * `MtoLib/`: 汎用ライブラリ。現在は主にANSIエスケープコードによる色付け機能を使用。
- ビルドシステム: `dotnet build`
- バージョン管理: Git

## アーキテクチャと機能
1.  **入力**: コマンドライン引数で指定されたファイル、またはパイプ経由の標準入力を受け取ります。
2.  **シンタックス定義の読み込み**: `keyword/C.cs` にハードコードされたJSON文字列から、C言語のキーワード、プリプロセッサ、型名などの定義を読み込みます。
3.  **ハイライト処理**: `Program.cs` 内で、正規表現を使用して入力されたテキストを行ごとにパターンマッチングします。ハイライトは以下の優先順位で適用されます。
    1.  コメント (`//...`)
    2.  文字列 (`"..."`)
    3.  特定の識別子 (`__FILE__`など)
    4.  プリプロセッサ (`#include`など)
    5.  キーワード (`int`, `if`, `for`など)
4.  **色付け**: マッチした部分文字列を、`MtoLib/ColorAnsiEscapeCode.cs` の拡張メソッドを使ってANSIエスケープシーケンスで囲み、コンソール出力に色を付けます。
5.  **出力**: 各行の先頭に行番号を付加し、ハイライトされたテキストをコンソールに出力します。

## 実装上の注意事項
- **シンタックス定義**: 新しい言語のサポートを追加する場合、`keyword`ディレクトリ内に新しいクラスファイルを作成し、`BaseKeyword`クラスに準拠したキーワードリストを定義する必要があります。現在の実装では、`Program.cs`でC言語の定義がハードコードされているため、動的に言語を切り替える仕組みが必要です。
- **ハイライトの優先順位**: ハイライトは正規表現のマッチング順に依存します。より具体的で長いパターン（例: `#ifdef`）が、より短い一般的なパターン（例: `#if`）より先に評価されるように、キーワードリストは内部で文字数の降順にソートされています。
- **MtoLibライブラリ**: `MtoLib`にはベクトル演算やCRC計算などの多くのユーティリティ関数が含まれていますが、`nccat`プロジェクトでは現在`ColorAnsiEscapeCode.cs`のみが利用されています。他の機能はプロジェクトの目的とは直接関係ありません。
